# Возврат клиентов ветклиники на прививки и процедуры в один клик: Telegram-бот, n8n, PostgreSQL и Ollama (Docker Compose, Cloudflare Tunnel)

Набор к ролику «Возврат клиентов в ветклинику в один клик». Каждое утро n8n находит в PostgreSQL питомцев, которым пора на прививку через 14 дней, локальная нейросеть Ollama пишет тёплое сообщение с кличкой, Telegram-бот присылает три свободных окна, клиент записывается одной кнопкой. Бот пишет только тем, кто сам дал согласие и номер через QR на стойке. Без абонентской платы за сервис: платите за сервер.

Канал с материалами: [@ByteAutomate_AI](https://t.me/ByteAutomate_AI). Внедрение под ключ: @konstantin_100.

```bash
git clone https://github.com/Kavilucky/ep49-vetclinic-recall && cd ep49-vetclinic-recall
```

## Что внутри
| Файл | Для чего |
|---|---|
| `docker-compose.yml` | PostgreSQL 16, n8n, Ollama, cloudflared (Cloudflare Tunnel); тома `pg_data`, `n8n_data`, `ollama_data`, `backups` |
| `.env.example` | пример настроек: пароль базы, ключ шифрования n8n, домен, токены туннеля и бота, чат администратора, модель Ollama |
| `init.sql` | таблицы `owners` (телефон E.164, согласие), `pets` (защита от дублей), `recall_schedule`, `free_slots`, `appointments`, `send_queue`, `owners_import`, функции `normalize_phone_e164` и `import_owners` |
| `vetclinic_recall_n8n.json` | сценарий n8n на 41 узел: согласие по QR, ежедневная выборка за 14 дней, текст Ollama, антиспам-очередь, запись по кнопке, ночное обслуживание; идентификаторы подключений пустые |
| `backup.sh` | резервная копия: дамп PostgreSQL и настройки (правило 3-2-1) |
| `Инструкция.txt` | пошаговый запуск и честные ограничения |

## Быстрый старт
1. VPS с Linux, Docker и Docker Compose; туннель и домен в Cloudflare Zero Trust (маршрут на `http://n8n:5678`); бот у @BotFather.
2. `cp .env.example .env`, значения сгенерируйте `openssl rand -hex 32`, впишите домен, токены, название клиники.
3. `docker compose up -d`, затем `docker compose exec ollama ollama pull qwen2.5:3b` (модель из `OLLAMA_MODEL`, пример), откройте `https://ваш_домен` и создайте администратора n8n.
4. В n8n импортируйте `vetclinic_recall_n8n.json`, создайте учётные данные Telegram и PostgreSQL, активируйте сценарий.
5. Разместите на стойке QR-код со ссылкой `t.me/ИМЯ_БОТА?start=reception`: клиент нажимает Start и «Поделиться номером и согласиться».

Аренда VPS: [Timeweb Cloud](https://timeweb.cloud/r/nf413716) (партнёрская ссылка, автор получает вознаграждение; условия на сайте, проверяйте актуальные).

## Честные ограничения
- Автор стек и сценарий на живом сервере и в живом n8n **не запускал**. Теги образов (`latest`), узлы Telegram, Postgres, записи файла, HTTP-запросы, формат ошибок и кнопка `request_contact` сверьте с документацией ваших версий.
- Telegram-бот не может первым написать человеку, который не нажал Start: поэтому согласие и номер собираются по QR на стойке (проверьте по документации Bot API). Из старой базы без этого рассылка невозможна.
- Номер, кличка и история прививок это персональные данные. Текст согласия, рассылка, хранение и срок хранения (152-ФЗ) проверьте у юриста. Это не юридическая консультация.
- Модель Ollama в примере не проверялась на качество русского текста; читайте результаты до массовой рассылки. Нужны ресурсы сервера под модель.
- Сумма потерь 110 000 ₽ в месяц, 2 500 карточек, срок 14 дней и цена внедрения 45-70 тыс. ₽ в ролике это сценарные примеры и оценки владельца. Условия бесплатного Cloudflare Tunnel проверяйте на сайте Cloudflare.
- Нужен бэкап базы по правилу 3-2-1: 3 копии, 2 носителя, 1 вне сервера; не удаляйте оригиналы, пока восстановление не проверено. Ночная выгрузка журнала в `backups` не заменяет полную копию.
